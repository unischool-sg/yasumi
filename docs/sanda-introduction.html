08 / OPTIONSやすみ？

OPTIONS TO DISCUSS

続け方は、一つに決めなくていい。

OPTION A / EFFICIENCY

まず送信を絞る

通知対象を必要な人に限定し、重複通知を減らす。判定結果はアプリで確認できるようにする。

OPTION B / PARTNERSHIP

学校・地域で支える

学校向け機能や地域の協力費として、月額の運営費を分担する。

OPTION C / CHANNEL

通知手段を分散する

LINEは入口にしつつ、Web Pushなどを加え、通知コストと依存先を分散する。

今日決めたいのは、料金プランではありません。三田市の家庭に役立つ形を保ちながら、誰がどの部分を支えると続けられるかを一緒に考えることです。
